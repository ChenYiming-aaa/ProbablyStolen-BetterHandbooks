# 更好的手册 / Better Handbooks

源码仓库：<https://github.com/ChenYiming-aaa/ProbablyStolen-BetterHandbooks>（Steam 工坊 ID `3830606413`）

给《Probably Stolen》加几件可以收纳纸张与招牌的册子/箱子。游戏把指南、彩票、配方书、名片、回执单
塞到你手里，却没给对应的收纳处，只能堆在抽屉里翻不着。这个 mod 把它们分开装。

## 七件收纳工具

| 收纳 | 装什么 | 谁送来 | 什么时候来 |
|---|---|---|---|
| **鉴定手册** | 7 张鉴定指南（香烟/手部/义体 ID/印章/注射器/燃料/肋明治）、海明威色卡、标识检查器、放大镜、四级鉴定证书 | 导师 | 鉴定委员会开放服务之后 |
| **彩票手册** | 号码彩票、旧彩票、刮刮乐（单张与整叠）、彩票信息纸 | 彩票代表 | 身上有彩票之后 |
| **生产手册** | 5 本原版配方书（水、水培、化学、金属锭、酒）+ 别家生产类手册（酿酒手册/酿酒水培、香烟手册/香烟水培、电脑装机指南） | 导师 | 身上有配方书之后 |
| **电话簿** | 6 种原版名片：酿酒、采矿、制药、化工、回收、乔；也收其它 mod 的名片 | 供应商 | 身上有名片之后 |
| **回执手册** | 治安部回执单（`sec_slip`） | 治安官 | 有 1 张回执之后 |
| **招牌箱** | 10 种霓虹招牌：水、食物、医疗、家居、材料、废机、枪械、重枪械、莓果、远征 | **不出门送** | 博士柜台上卖 1 块 |
| **万能手册** | 你在设置里逐本勾选的任何手册（默认一本不勾） | **不开门送** | 勾了「我要万能手册」后，下次开门直接放你柜台 |

**容量**：默认鉴定 10×10、彩票 6×6、生产 10×10、电话簿 6×6、回执 6×6、招牌箱 10×8、万能 10×10。七件都能改，见下面「改容量」。

**送来规则**：条件满足当天只记日子，第二天人物才上门；一天最多来一位；当天不接待，隔天他会再来，直到你收下。手上已经有这本册子的人不会重复收到。

册子放在**柜台上**，不是抽屉里 —— 一收下就能看见。

**招牌箱不在赠送队列里**：晚上去博士那儿，他的柜台上会摆一只，标价 1 块，买不买随你。**买过一次就永久下架**——扔了、卖了，他也不会再进货。

**七件都会换样子**：册子空着和装着东西长得不一样——格子里放进任何一件东西，封顶那条深色带就变成「露出纸页」的样子（和原版导师手册同一处理），清空再换回空图。招牌箱则是空玻璃箱 ↔ 塞满灯牌两种样子。

**治安官会看你的成绩说话**：抓到的通缉犯越多、近期错报越少，他越客气；错报两次以上，语气就不一样了。台词分三档，各 5 句。

> 册子是**空的收纳容器**，不会凭空生成指南纸、证书或名片。里面能装的东西，仍然要你自己去解锁、去买、去收。

## 安装

1. 订阅创意工坊条目（或把 `BetterHandbooks` 文件夹复制到 `Probably Stolen\Mods\`）。
2. 启动游戏 → 主菜单的「模组」列表里启用**更好的手册**。
3. 读档或开新档。模组只在你开始新的一天时安排上门，所以**睡一觉**才会触发。

不需要装 Harmony 之类的前置：游戏本体已经自带。

## 收纳规则一览

| 收进鉴定手册 | 不收 |
|---|---|
| 7 张鉴定指南纸、海明威色卡、共和国标识检查器、放大镜、初级/认证/高级/大师鉴定证书 | 配方书、彩票、名片、合同、证件、单据、报刊、职业卡、通缉令 |

生产/加工类的配方书单独进生产手册，不会被鉴定手册抢走；彩票信息纸同理只进彩票手册。

**别家手册默认按内容各归各位**（都带 `GUIDE_PAPER_TAG`，但归属不同）：

| 类别 | 手册 | 默认归哪本 |
|---|---|---|
| 生产配方类 | 酿酒手册、酿酒水培手册、香烟手册、香烟水培手册、电脑装机与交易手册 | 生产手册 |
| 鉴定类 | 果味香烟真伪鉴定手册 | 鉴定手册 |
| 工具书/目录类 | 枪匠手册、枪械目录 | 留在店里（无专属册子，需手动勾给万能手册） |

**这 6 本默认进各自的基础册子**，不依赖万能手册。你也可以在设置里逐本勾选把它们同时交给万能手册——**一本手册可以被两本册子同时认领**，实际进哪本由你拖到哪本、或自动整理的优先级决定；勾选并不会让专属册子拒收。

**万能手册收什么完全看你勾选**：打开设置页时会扫描所有文档（读档后还会自动补扫一次），按来源 mod 分组列出每本手册的名字，你勾哪本它就收哪本，默认一本不勾。任务关键文档（identifier 带 contract / certificate / archive / commission / order / slip 等）根本不出现在清单里，也不会被收，免得卡住交付。详见下面「万能手册：按名字勾选」。

回执手册只认 `sec_slip`；`slip`（通用手写单据）和 `procurement_slip`（采购回执）是任务中间物，故意不收。
招牌箱收原版 10 种招牌（按 id 前缀 `sign_` 认，`sign_berry` 连标签和物品类型都没有，按标签收一定漏），也收其他 mod 的招牌（1.7.3：标识符含 `sign` 且带 `SHOWCASE_SPECIAL_ITEM_TAG`，如酿酒/香烟/枪匠/装机/借贷拓展的灯牌）。招牌不是文档类物品，不进万能手册。
七件收纳工具自己不会被任何册子收进去（包括万能手册）。

## 设置界面（1.6.0 起分两页，1.6.1 起主菜单即时生成清单）

主菜单「模组」列表 → 选中**更好的手册** → 设置。界面分成两个标签页，功能一个不少：

**第一页「册子大小」**：顶部是「放入档案箱后自动整理」开关（默认关，见下），下面是六本基础册子，每本的**宽和高放在同一行**，各带滑块 + 数字框，范围 2~16。

- 拖滑块即时生效，右侧数字框直接显示当前格子数，也可以点进去改数字（回车或点「应用」生效）。
- 改完**立即套用**到已经拿到的册子上，不用重收。
- 放大随时可以；**缩小只在里面的东西仍放得下时才生效**，否则保持原尺寸（不会把纸挤掉）。

**第二页「万能手册」**：要不要、它的大小，以及"收录哪些手册"——这一节是**打开设置页时自动生成**的；主菜单就能看到已装 mod 的手册，读档后再自动补扫一次：

- **我要万能手册（开门放柜台）**：勾上后，下次开门时如果店里没有万能手册，就直接放一本到你的柜台，不用再等谁送来。取消后不再自动放，已有的册子和里面的东西都保留。
- **收录哪些手册 · 按来源 mod 分组**：每个 mod 一节，下面列出它带来的每一本手册，显示游戏里的中文名（跟着游戏语言走）。**每本一个勾选框，默认都不勾**：
  - 勾上 → 这本以后也能进万能手册（专属册子照收不误）；
  - 不勾 → 维持默认归属（生产类进生产手册、鉴定类进鉴定手册、其它留在店里）；
  - 点「应用」立即生效，不用重开。
- 装了新 mod、或 mod 更新加了新手册：**下次进游戏，清单会自动多出它们的名字**，不用改代码。
- 「游戏原版」一节列出原版自带的说明书/信息纸（如彩票信息纸），同样逐本勾选。

设置存在 `ModConfigs\better.handbooks.json`，删除该文件即恢复默认。

> 清单里的名字来自各 mod 自己的汉化，显示成什么就勾什么。看不懂的可以对照 identifier——勾选框的提示里有。

## 档案箱自动整理（默认关闭，设置里可开）

**默认关闭**（1.7.6 起）：放进档案箱的东西会原样留着。想要自动归类，到设置第一页勾上「放入档案箱后自动整理」即可——之前就开着的人不受影响，设置会保留。

开启后，把书面的纸放进游戏里原本就有的**档案箱**（dossier，开局就在店里、专门收各种纸的 10×10 箱子），本 mod 会**立刻**按下面的顺序自动归位，不用你一本本拖：

1. **专属册子**：先塞进能收它的那本——鉴定/彩票/生产/电话簿/回执，招牌进招牌箱；别家 mod 的手册按其默认归属进生产或鉴定手册；
2. **万能手册**：专属册子没有、或塞满了，再试万能手册（只收你勾选过的）；
3. **留在档案箱**：两处都放不下（或你还没拿到对应册子），就原样留在档案箱里，不会丢。

只会整理**你店里已经有的**册子；没拿到那本册子就不动它。用的是游戏自己拖放物品的那条路径，塞不进就保持原状。任务关键文档（合同/证书/档案等）不参与自动整理。1.6.2 起改用双通道检测放入，修复了原先整理不触发的问题；1.6.3/1.6.4 起在物品进入档案箱**之前**就分流，批量和单件拖放都不再要求档案箱先空出位置，册子收得下的部分直接进册子。

**读档时不整理**（1.7.5）：游戏读档会把档案箱内容逐件重建，以前这会连带触发自动整理，文档多时会卡住加载、个别情况下还会把纸弄丢。现在读档期间自动整理暂停，档案箱里的东西原样保留；只有你**主动**把纸放进去时才整理。

## 兼容与安全

- 不改任何游戏数值，不新增掉落。设置（容量、勾选）都存在游戏自带的 `ModConfigs\better.handbooks.json` 里，删除该文件即恢复默认。
- 只补两处原版没做完的地方：`inspection_book`（原版定义了但从未发放）、冶金指南漏掉的 `GUIDE_PAPER_TAG` 标签。
- 卸载后，已经拿到的册子仍然是一本正常的原版文档容器，里面的东西不会丢。
- 存档里只多出几个物品和几个字符串标记（`sent_*` / `ready_*` / `bought_*` / `offered_*`）。

## 已知限制

- 每件册子/箱子在格子里占 **2×3 或 3×2 格**（招牌箱）。普通物品要放进档案箱时，档案箱里得先空出一块这么大的位置，否则会因为"没有可落的位置"被拒——这不是 bug，和原版放不下任何物品时一样。能被本 mod 自动归位的手册走 1.6.3（批量）/1.6.4（单件拖放）的入口分流，不需要先占档案箱格子；但没有任何册子肯收时，仍按原版规则受空位限制。
- 容量可以改，但**只放大不缩小**：缩小后若里面还有东西放不下，册子保持原尺寸，设置里那个数字不生效。
- 别的 mod 的名片没有统一标签，电话簿按 identifier 判断（含 `card` 的文档类物品），或认 `BETTERHB_CARD_TAG` 标签。两者都不满足的，会进不去。
- 招牌箱买过一次就不再进货，包括你不小心把它扔了的情况。
- **不要在模组菜单里停用本 mod 后读档、保存**（1.7.4 起）：游戏会把七件手册当未知物品、清空里面的内容，一旦保存就永久丢失（游戏只会补发鉴定证书，其他内容补不回来）。1.7.1–1.7.3 曾有内容备份试图兜底，但因缺陷与价值有限已移除。正常启用、正常开关其他 mod 不受影响。
- 每天只安排一位上门的人，依次排队。
- 只支持简体中文与英文界面。其他语言会回退到中文文案。

## 目录结构

```
BetterHandbooks/
  manifest.xml              模组信息（ID / 版本 / 依赖 / 声明的能力）
  BetterHandbooks.dll       程序集
  Localization/             zh.csv、zh-Hans.csv、en.csv（文件名即 Locale Code）
  Textures/Items/           手册图标 32×48（2×3 格）+ 各自的 *_full「装满」版，招牌箱 48×32（3×2 格）
```

图标想自己重画的话，`tools/ICON_PROMPTS.md` 里有五本册子的生图提示词（正向/负向/步数等参数，含本机 Z-Image 实测配置与实跑结论）；`tools/run_comfy_zimage.py` 通过 `127.0.0.1:8188` 调本地 ComfyUI 批量出图到工作区 `generated-images/zimage_icons/`；`tools/ai_icon_to_game.py` 负责按四角基准色抠底、清碎块、缩到 32×48、alpha 二值化，并打印格子占用图供校验。这三个工具都不改游戏目录里的贴图。

「装满」状态的图标不用重画：`tools/make_filled_icon.py` 把原版导师手册空/满参考图的像素 diff（顶部 4 行的露出纸页）按各册子调色板直接套到现有图标上，跑一遍就生成六张 `*_full.png`。在项目根目录下运行：`D:/Anaconda3/python.exe tools/make_filled_icon.py`。

2026-11-10 用本地 Z-Image Q4 实跑了五张（`generated-images/zimage_icons/sheet_compare.png` 是新旧对照）。结论：徽记都能认出，但配色偏亮、顶部标签条过大、左侧多一列装订环，仅作概念稿，**未替换** `Textures/Items/` 里的任何图标。

技术实现与反编译核对记录写在项目内的 `DEVNOTES.md`（不随包发布）。
